# Showcase capture notes

The README images are captures of the running application, not design mockups. They use only synthetic demo data.

## Reproduce the preview

Run the Capture preview workflow from GitHub Actions, or launch the debug app on an API 35 emulator. `scripts/capture_preview.py` installs the APK, starts MainActivity, checks the feed and Favorites labels, and saves an ADB screenshot. The README image comes from [run 40437934443](https://github.com/Ke1no/MelodyNest/actions/runs/40437934443).

## Interpretation

Screenshots document the visible state of this development scaffold. They do not imply a public deployment, production readiness or completion of planned features. See the README for implemented scope and validation.

The screenshots show the current MelodyNest branding and replace the earlier preview assets.
