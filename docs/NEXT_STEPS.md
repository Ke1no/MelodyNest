# Next steps

1. Open the repository root in Android Studio, install SDK 35, sync the project and start an emulator.
2. Check the Feed, Albums and Favorites navigation entries. Open an album's track list, add a favorite and restart the app to verify persistence.
3. Select Play to test the demo audio. It is a generated melody, not a real song.
4. Start `mock-api` and select Refresh mock API to verify Retrofit requests. For a physical device, adjust the debug API address as described in the README.
5. Add cover art, a progress bar, a playback queue, next-track controls, search, and complete error and empty states.
6. When background playback is needed, add MediaSessionService, notifications, and audio-focus and lifecycle tests.
7. Connect licensed audio sources, complete Room migrations and tests, then record a demo.
